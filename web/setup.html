如何重新初始化？

停止正在运行的服务后执行 endlessvibe --init 即可。现有配置、Owner Key 和项目授权都将保留。

将 MCP 地址添加到 ChatGPT

等待配置…

  1. 确认隧道和服务正常运行；HTTPS 域名必须能够访问 /mcp 与 OAuth 元数据。
  2. 在 ChatGPT Plugins ↗ 创建自定义 MCP 服务，粘贴上述地址并选择 OAuth。
  3. 在 EndlessVibe 授权页面使用本机 Owner Key 完成授权，然后在 ChatGPT 中选择 EndlessVibe。
  4. 尝试读取已授权 Project，以实际工具调用确认连接成功。
Owner Key 存储位置—

不要将 Owner Key、Token 或其他凭据粘贴到 ChatGPT 对话或 MCP URL 中。

公网连通与 ChatGPT 授权不会通过本地向导自动宣称验证成功。
