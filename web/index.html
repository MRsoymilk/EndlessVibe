RESTART REQUIRED · HOST SECURITY


Windows AppContainer 提供原生离线命令沙箱，任务使用独立身份、项目文件权限与 Job Object。host 模式的 Job Objects 仅限制资源和进程树。保存后需重启 EndlessVibe，以“当前运行”显示为准。








高风险：host 模式不提供沙箱隔离。启用后，已获执行权限的 Project 和配对父节点可在当前服务账号权限范围内运行本机命令，包括访问该账号可读取的文件与网络。

Job Objects检查平台
Windows 上限制任务的进程树、内存和进程数量。不能阻止读写服务账户可访问的文件或访问网络。

Readonly Mounts
RESTART REQUIRED
直接编辑 [execution].readonly_mounts。Source 必须是宿主机已存在的绝对路径；Target 必须位于 /opt/... 或 /cache-readonly/...。保存只写入配置，不会热重载，重启 EndlessVibe 后生效。



Limits
RESTART REQUIRED
在线修改 [limits]；数值通过服务器验证并保存，重启 EndlessVibe 后生效。单位为 bytes / seconds。


Git
RESTART REQUIRED
修改服务的 Git 可执行文件路径及提交身份。更改不会执行 Git 命令或推送代码，重启后生效。


Transfer / LAN Nodes
RESTART REQUIRED
开启 Transfer 后发布局域网发现信息，并通过独立 TLS 端口接收配对/授权操作。不会把本地 Dashboard 或 MCP OAuth 入口开放到局域网。


Docker MCP
RESTART REQUIRED · PRIVILEGED
Docker Engine Unix socket 具有接近宿主机管理员的权限。默认关闭；启用后必须指定允许访问的精确容器名称，并单独授权启动/停止/重启。普通 development Job 不再默认获得 Docker socket。此处只配置权限，不会立即操作容器。


Storage Health
STORAGE
按用途查看状态目录的磁盘占用。缓存扫描最多覆盖 20,000 节点，显示“至少”表示结果不完整。清理执行缓存只影响 exec-cache，后续 Cargo / CMake 构建可能需要重新生成缓存。
Execution Cache—可清理的构建与工具缓存
SQLite + WAL—持久 Job / Activity / Tasks
Backups—保留，不参与缓存清理
